Лабораторная работа №3

Объекто-ориентированное программирование

Проект представляет собой реализацию ключевых абстрактных структур данных (динамический массив, списки, стек, очередь, хеш-таблица, бинарное дерево) на двух языках программирования (C++ и Go), их сериализацию/десериализацию, комплексное модульное тестирование с покрытием не менее 85%, бенчмаркинг и генерацию интерактивных HTML-отчетов.
